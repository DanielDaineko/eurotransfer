# EuroTransfer

Premium transfer service website for Estonia built with React + Vite.

🔗 Live Demo: https://eurotransfer.ee

---

# Features

- Multi-language support (EE / RU / EN)
- Premium dark luxury design
- Fully responsive layout
- Animated UI sections
- Route showcase
- Interactive map section
- Contact integration
- Mobile-friendly navigation
- Optimized deployment with Vercel

# Installation

Clone the repository:

```bash
git clone https://github.com/DanielDaineko/eurotransfer.git
```
Go to project folder:

```bash
cd eurotransfer
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

# Build

Production build:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

# Project Structure

```bash
public/
  images/           # images, icons, favicon

src/
  components/       # Header, Hero, Services, Footer
  data/             # routes and static data
  hooks/            # custom hooks
  locales/          # translations (EN, RU, ET)
  styles/           # global styles and variables

  App.jsx           # main app component
  i18n.js           # i18next configuration
  main.jsx          # React entry point

root/
  package.json      # dependencies
  vite.config.js    # Vite configuration
  README.md         # project documentation
```
